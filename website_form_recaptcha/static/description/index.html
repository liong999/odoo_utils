Web Login reCAPTCHA

Secure Odoo Backend & Web Login with Google reCAPTCHA v2 & v3

Key Features

Brute-Force Protection

Blocks automated bot attacks, credentials stuffing, and malicious login attempts before authentication occurs.

Multi-Version Support

Flexible configuration allowing you to switch between Google reCAPTCHA v3 (Invisible) and v2 (Checkbox) seamlessly.

Native Settings Integration

Integrates directly into Odoo Settings > General Settings > Integrations alongside default reCAPTCHA configurations.

reCAPTCHA v2 Checkbox FEATURED

Provides a full backend API verification engine for Google reCAPTCHA v2 "I'm not a robot" interactive checkboxes.

reCAPTCHA v3 Invisible

Silent risk scoring that detects human behavior without disrupting user login flow with interactive challenges.

Responsive UX

Optimized widget rendering for both desktop browsers and mobile web interfaces with clear user error messaging.

Understanding reCAPTCHA Versions

Off

Completely disables reCAPTCHA validation on the backend login form. Standard authentication proceeds without captcha token checks.

v3 (Invisible)

Monitors login requests seamlessly in the background. Google assigns a risk score based on interaction patterns without forcing users to solve puzzles or check boxes.

v2 (Checkbox)

Displays an explicit "I'm not a robot" checkbox widget on the login form. Requires explicit user interaction before submitting login credentials.

Configuration & Setup Guide

  • 1. Module Installation: Install web_login_captcha from the Apps menu.
  • 2. Access Settings: Navigate to Settings > General Settings > Integrations.
  • 3. Enter reCAPTCHA Credentials: Input your Google reCAPTCHA Site Key and Secret Key.
  • 4. Select Version: Choose your preferred ReCAPTCHA Version (Off, ReCAPTCHA v3 (Invisible), or ReCAPTCHA v2 (Checkbox)).
  • 5. Save & Test: Click Save. Log out and visit the login page to verify the reCAPTCHA widget in action.
